# Video Interactivo — Laplace Challenge

Prototipo sin H5P para Moodle.

## Cómo probarlo
1. Extrae esta carpeta.
2. Abre `index.html` en Chrome/Edge/Firefox.
3. El video ya está dentro de `videos/Clase_2_p1.mp4`.
4. Durante el video aparecerán 6 retos y el sistema asignará XP.

## Archivos
- index.html → estructura de la página
- style.css → diseño
- script.js → pausas, preguntas, puntos y resultado
- videos/Clase_2_p1.mp4 → video original

## Para Moodle
Este prototipo funciona como una aplicación web independiente. Para integrarlo en Moodle, primero hay que subirlo a un servidor/hosting accesible por los estudiantes y después enlazarlo o incrustarlo desde Moodle, según los permisos de la institución.

## Importante
La puntuación de este prototipo se mantiene en la sesión del navegador. Todavía NO envía la nota al libro de calificaciones de Moodle. Esa será una segunda etapa de integración.
